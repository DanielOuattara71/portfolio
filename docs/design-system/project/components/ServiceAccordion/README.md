# ServiceAccordion

Liste des services en grandes capitales. La ligne ouverte déplie une boîte sombre avec la description, les problèmes résolus et un visuel incliné.

## Contenu (depuis l'admin, FR et EN)
- Titre du service : formulé comme un domaine (« IA & automatisation »).
- Description : une phrase sur le problème résolu.
- 2 à 4 cas concrets en liste.
- Visuel optionnel (capture d'un projet lié), incliné de -3°.

## Règles
- Une seule ligne ouverte à la fois ; la première est ouverte au chargement.
- `aria-expanded` + `aria-controls` sur chaque en-tête.
- Ne promettre que des services adossés à une pratique réelle (module Compétences de l'admin).

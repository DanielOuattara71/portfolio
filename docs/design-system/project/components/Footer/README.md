# Footer

Panneau sombre de fin de page, sur le modèle d'aquidev : phrase d'appel, bouton rond, liens, signature géante.

## Contenu (depuis l'admin)
- Phrase `display-statement` avec un mot clé en `accent-italic`.
- RoundCTA vers le contact.
- Liens : LinkedIn, GitHub, email (affiché en texte copiable), CV.
- Signature : prénom en contour, nom en plein, capitales, `aria-hidden` (le nom est déjà dans la page).
- Mentions : année, titre, langues.

## Règles
- Toujours le dernier élément de la page, une seule fois.

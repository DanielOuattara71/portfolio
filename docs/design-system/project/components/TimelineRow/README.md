# TimelineRow

Ligne d'expérience ou de formation dans le panneau sombre /PARCOURS : organisation, type, rôle, dates.

## Contenu (depuis l'admin)
- Organisation + badge de type (stage, emploi, freelance, formation, certification).
- Rôle ou diplôme en une ligne.
- Dates au format « mois année – mois année » ou « en cours ».

## Règles
- Ordre antichronologique.
- Les missions détaillées vont dans la page Parcours, pas dans la ligne.
- Jamais de ligne avec un nom d'organisation vide.

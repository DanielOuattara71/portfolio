# StatPill

Pastilles de faits sous les boutons du Hero. Le chiffre ou le mot clé est en police `data`.

## Règles
- Uniquement des faits vérifiables, calculés depuis la base (nombre de projets publiés) ou saisis dans l'admin. Jamais de chiffre d'audience ou de résultat inventé.
- Trois pastilles au plus.

# Badge

Étiquettes en police `data` posées sur les médias et les lignes : identifiant d'enregistrement (fond `marker`), type de projet, contexte.

## Variantes
- `.ix-badge--id` : identifiant (`PRJ-02`), fond `marker`. Un seul par carte.
- `.ix-badge` : type ou contexte (« projet client », « stage · Smart Innovation 7 »), fond `surface-raised`.
- `.ix-badge--kind` : sur fond sombre (« stage », « formation »).
- `.ix-count` : compteur entre crochets à côté d'un titre.

## Règles
- Minuscules, sauf les identifiants.
- Le contexte d'un projet est saisi dans l'admin, jamais inventé.

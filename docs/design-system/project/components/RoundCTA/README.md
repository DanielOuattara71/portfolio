# RoundCTA

Gros bouton rond orange (150px) qui ouvre le contact. Un seul sur le site, dans le footer.

## Règles
- Fond `marker`, texte `on-marker`, posé sur `surface-inverse`.
- Effet magnétique sur ordinateur uniquement : il suit le curseur de 25 % de l'écart, puis revient avec `ease-out` sur `duration-slow`. Désactivé au toucher et avec animations réduites.
- Libellé d'un mot (« Démarrer ») et une flèche.

# RecordFields

Liste de champs « nom → valeur » en police `data`, la signature « fiche » du site. Utilisée dans les cartes projet, la fiche profil et les études de cas.

## Règles
- Noms de champs en minuscules : stack, rôle, période, statut, lien.
- Valeur absente : « à compléter » en `ink-muted` dans les maquettes ; en production, la ligne est masquée.
- Technologies séparées par ` · `.

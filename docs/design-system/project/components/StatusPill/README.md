# StatusPill

Pastille de disponibilité avec un point vert qui pulse. Le texte vient de l'admin (Paramètres → disponibilité).

## Règles
- Le point `success` est toujours accompagné du mot : la couleur seule ne porte pas l'information.
- Indisponible : la pastille est masquée, pas recolorée en rouge.
- Animations réduites : le point ne pulse plus.

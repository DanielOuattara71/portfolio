# SectionTitle

Titre de section écrit comme une route (`/PROJETS`), avec un compteur réel et un mot fantôme géant derrière.

## Contenu
- Titre : `/` + nom de la section, en capitales (`display-section`).
- Compteur entre crochets : nombre réel d'éléments publiés.
- Chapeau optionnel en `body-lg`, 52 caractères de large au plus, avec un mot clé en `accent-italic`.
- Mot fantôme : un mot lié à la section (« Records », « Services »), `ink` à 4,5 % d'opacité, `aria-hidden`.

## Règles
- Le mot fantôme est décoratif : jamais d'information dedans.
